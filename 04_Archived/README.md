# 🗄️ Archived Contributions

This folder stores contributions that have been:
- ✅ **Processed** — already integrated into a skill (kept for traceability)
- ❌ **Rejected** — not suitable for integration (reason noted inside the file or in a companion `_REASON.md`)
- 🔁 **Superseded** — replaced by a newer, more accurate entry

## Structure
Files are stored flat in this folder with the prefix `ARCHIVED_` to distinguish them from active contributions.

**Example:**
```
ARCHIVED_STL_ForceVoltage_NullRefError.md
ARCHIVED_Hardware_PXI_TriggerRouting_Issue.md
```

## Retention Policy
Archived files are kept indefinitely for audit and traceability purposes. Do not delete files from this folder without team lead approval.
