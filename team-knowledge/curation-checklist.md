# Knowledge Curation Checklist

A submission is approved only if all required checks pass.

## A) Technical Quality
- [ ] Problem and expected outcome are clearly stated
- [ ] Solution is technically correct
- [ ] Steps are reproducible
- [ ] Validation evidence is present and credible

## B) Scope and Reusability
- [ ] Case is generalized enough to help future tasks
- [ ] Scope boundaries and assumptions are explicit
- [ ] Caveats/failure modes are documented

## C) Skill Routing Quality
- [ ] Candidate skill(s) are correctly tagged
- [ ] Domain/language/API tags are complete
- [ ] Reuse guidance clearly states when to apply/avoid

## D) Security and Compliance
- [ ] No secrets or credentials
- [ ] No sensitive customer/project identifiers
- [ ] No content that should not be redistributed

## E) Curation Outcome
- Decision: Approved / Needs Revision / Rejected
