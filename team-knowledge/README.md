# Team Knowledge Workflow Assets

This folder contains shared assets for collecting and curating team knowledge for skill ingestion.

## Structure
- `templates/case-submission-template.md` - teammate intake template
- `templates/curated-record-template.md` - normalized approved-record template
- `templates/skill-knowledge-entry-template.md` - per-skill concise knowledge entry template
- `curation-checklist.md` - reviewer approval checklist
- `ingestion-runbook.md` - end-to-end submission-to-skill workflow
- `index-update-procedure.md` - exact index maintenance steps
- `indexing-guidelines.md` - index schema and governance rules
- `knowledge-submissions/` - raw teammate submissions
- `knowledge-curated/` - approved normalized records
