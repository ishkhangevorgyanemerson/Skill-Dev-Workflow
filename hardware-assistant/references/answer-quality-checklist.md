# Answer Quality Checklist

Use before returning any response.

## Required
- [ ] The answer directly addresses the user's question
- [ ] Assumptions are explicit
- [ ] Steps are actionable and ordered
- [ ] Validation criteria are included

## Troubleshooting-Specific
- [ ] Fault classes are prioritized by likelihood
- [ ] Verification sequence is short and deterministic
- [ ] Expected observations are stated
- [ ] Next branch is clear for each outcome

## Safety and Reliability
- [ ] No unsafe recommendation without caveats
- [ ] No fabricated data or certainty claims
- [ ] Escalation guidance provided when uncertainty remains
