# 🧠 AI Skills Library

This folder contains the **built and maintained AI skills** for the team. Each skill is owned and curated by the Skill Owner (team lead).

## Skills Overview

| Skill | Description | Status |
|-------|-------------|--------|
| `STL_Skill/` | Answers questions about the NI Semiconductor Test Library | ✅ Active |
| `Hardware_Skill/` | Troubleshoots hardware setup and instrument issues | 🚧 In Progress |
| `General_Skill/` | General test & measurement guidance | 🚧 In Progress |

## Skill Structure

Each skill folder contains:
```
<Skill_Name>/
├── README.md           # Skill description, scope, and usage
├── skill_config.md     # Prompt configuration and skill metadata
└── knowledge_base/     # Curated Q&A and reference entries
    ├── entry_001.md
    ├── entry_002.md
    └── ...
```

## Versioning

Skills are versioned using Git tags: `STL_Skill_v1.0`, `STL_Skill_v1.1`, etc.
