# STIL to Digipatsrc

Python CLI for converting STIL files into NI STS-compatible outputs.

## Install

From this folder:

```powershell
pip install .
```

## CLI

```powershell
stil-to-digipatsrc input.stil output.digipatsrc --pinmap Pinmap
```

## Included modules

- `stil_parser.py`
- `digipatsrc_generator.py`
- `stil_to_digipatsrc.py`
