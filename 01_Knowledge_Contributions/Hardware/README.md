# 🔧 Hardware Contributions

This folder contains knowledge contributions related to **hardware setup, calibration, and instrument-specific troubleshooting**.

## Examples of valid contributions
- SMU configuration issues
- PXI chassis or trigger routing problems
- Instrument driver version compatibility
- Calibration workarounds
- Wiring and fixturing best practices

Use [`../../05_Templates/contribution_template.md`](../../05_Templates/contribution_template.md) to structure your submission.
