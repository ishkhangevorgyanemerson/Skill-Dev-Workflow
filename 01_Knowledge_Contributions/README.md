# 📥 Knowledge Contributions

This folder receives raw knowledge contributions from team members.

## Subfolders

| Folder | Description |
|--------|-------------|
| `STL/` | Issues, Q&A, and solutions related to the NI Semiconductor Test Library |
| `Hardware/` | Hardware setup, calibration, instrument-specific troubleshooting |
| `General/` | General test & measurement questions and best practices |

## How to Add a Contribution

1. Pick the correct subfolder for your topic
2. Use the template from [`../05_Templates/contribution_template.md`](../05_Templates/contribution_template.md)
3. Name your file: `ShortDescription_Issue.md` (e.g., `ForceVoltage_CurrentOverflow.md`)
4. Commit or open a Pull Request

The skill owner will review and integrate your contribution into the appropriate skill.
