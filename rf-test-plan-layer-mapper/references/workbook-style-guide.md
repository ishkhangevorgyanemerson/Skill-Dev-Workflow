# Workbook Style Guide

- Prefer candidate discovery before editing.
- If the workbook has multiple sheets, ask which sheet is the main test plan.
- If the selected sheet lacks a mapping column, create one automatically in a style-aware location.
- For E6, create three columns after `Test Name` and merge contiguous identical NI families.
- For LIMIT_RF, create one column after `Item` and merge contiguous identical scenario families.
